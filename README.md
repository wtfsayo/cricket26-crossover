# Cricket 26 on Mac with CrossOver

Run an owned Microsoft Store **PC/GDK** copy of Cricket 26 on **Apple Silicon macOS** using **CrossOver, DXMT, WineGDK and Xodus**, without booting Windows. This open-source repository preserves the method, source patches and replay scripts from a working installation.

The preserved setup passed sign-in, loaded an England vs Australia match, and rendered an on-field delivery on 12 September 2026. The user confirmed that the game was working. It used CrossOver 26.3, DXMT, a patched WineGDK runtime, and a patched Xodus service with real Microsoft account/license requests. Saves stay on the Mac.

This repository contains instructions, source patches, probe sources, build scripts, and download/extraction helpers. It contains no game assets, compiled runtime binaries, Microsoft DLLs, saves, account credentials, tokens, or private diagnostic logs.

## Tested configuration

| Component | Working configuration |
| --- | --- |
| Mac | Apple Silicon, macOS 27.0 |
| CrossOver | 26.3, Windows 10 x64 bottle |
| Graphics | DXMT |
| Game | PC package 3.69.0.0; title-screen version 1.0.3504 |
| Authentication | Owning Microsoft account, normal Xodus login and macOS Keychain |
| Saves | Local files inside the isolated bottle; no Xbox cloud sync |

This runs the Windows PC game through compatibility software. It does not use an Xbox OS image, console emulator, UTM or Parallels. The pinned build tools, native threading DLL and source revisions are listed in the [method](docs/METHOD.md#working-versions).

## Get the sources

Clone the public repository:

```sh
git clone https://github.com/wtfsayo/cricket26-crossover.git
cd cricket26-crossover
python3 scripts/check.py
```

The check runs offline in temporary directories. It does not download the game, access an account, or modify an installed bottle.

## Reproduce the method

Read [the method](docs/METHOD.md) for prerequisites, pinned versions, downloading and extracting the owned package, building the runtime, configuring the bottle, and launching. [The chronology](docs/CHRONOLOGY.md) records the failures and changes that led to gameplay.

The scripts under `source/` preserve the working implementation. Shell scripts contain `@GAME_ROOT@` and `@HOME@` placeholders. `scripts/prepare.py` renders them into an external workspace and refuses to overwrite different existing files:

```sh
python3 scripts/prepare.py "$HOME/Downloads/Xbox-Games/Cricket-26" \
  --xodus-source "$HOME/.local/share/xodus/source"
```

Follow the clone/checkout/lockfile instructions in the method before preparation. Preparation performs no downloads, builds, login, or game launch. Account access still requires normal Xodus login and macOS Keychain approval. No account credentials are bundled or generated by these scripts.

## What is and is not verified

- The original Mac installation reached actual gameplay. Authentication, local saves, and Store async completion were exercised separately.
- The patches apply to their pinned upstream commits. Repository helper checks are described in [verification](docs/VERIFICATION.md).
- A fresh Mac installation has not been tested. This is a reconstruction kit, not a one-command installer or a general compatibility guarantee.
- Xbox cloud-save synchronization, online multiplayer, every game mode, and long-session stability remain unverified. DXMT worked; no comparative graphics benchmark was performed.

Keep the approximately 195 GiB package/extraction workspace outside this repository. The recorded version-specific CDN URL may cease working. The package hash is our local reference, not a publisher-signed checksum. A valid owning Microsoft account is required for license acquisition.
